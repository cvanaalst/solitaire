# Adding Solitaire to your iPad or iPhone

Solitaire is a Progressive Web App. Once it is on your home screen it runs full screen, like any other app, and it keeps working when you are out of wifi.

## The short version

Open **[https://cvanaalst.github.io/solitaire/](https://cvanaalst.github.io/solitaire/)** in Safari and follow the steps below. It takes about a minute.

## English

### 1. Open the link in Safari

Tap **Safari**. If the link opens in another app, choose **Open in Safari**.

### 2. Tap Share

Tap the Share button (the square with an arrow). On an iPad it is in the top right, on an iPhone at the bottom. If you cannot see it, tap the **⋯** button first.

### 3. Scroll down and tap Add to Home Screen

Scroll down the list of options until you find **Add to Home Screen**.

### 4. Leave Open as Web App switched on, then tap Add

Keep **Open as Web App** switched on, then tap **Add**.

### Done

Tap the new Solitaire icon to play. It works without internet too.

## Why the steps matter

**Use Safari, not Chrome.** On iOS, only Safari can add a web app to the home screen. Chrome and Firefox on the iPhone and iPad open the game in a normal browser tab with no home screen icon.

**Leave "Open as Web App" switched on.** With it on, the app opens without Safari's address bar or toolbar, so it looks and behaves like a native app. If you turn it off you still get an icon, but it opens with the browser chrome around it.

**No account, no download, no App Store.** The whole game is a set of files on a web server. Adding it to the home screen does not install anything in the traditional sense, it just tells Safari to remember the address.

## After you have added it

- **It works offline.** The first time you open it, the app copies itself onto the device. After that you can play in a plane, on a beach or in a basement.
- **Updates arrive on their own.** The next time you open the app it checks for a newer version and tells you when it has updated. The version is shown on the splash screen, so you can always tell what you are running.
- **Your game is saved automatically.** Close the app mid-game, come back later and your board is exactly where you left it.
- **To uninstall**, long press the icon and choose Delete App. Nothing is stored on your device that you need to clean up beyond that.

## If something goes wrong

**I cannot see the Share button.** Scroll the top bar to the far right, or tap the **⋯** button in the address bar first.

**The icon looks wrong or the game opens with a Safari bar.** Delete the icon, then add it again with **Open as Web App** switched on.

**The page is blank.** Make sure you are on `https://cvanaalst.github.io/solitaire/` and not a shortened or mistyped address. A secure connection is required, which is why the `http://` version of the address will not install.

**I want the single file version instead.** There is one file with everything inlined at [dist/solitaire.html](https://cvanaalst.github.io/solitaire/dist/solitaire.html). Download it and open it from the Files app. It plays straight away, but it cannot be added to the home screen and it does not work offline.
